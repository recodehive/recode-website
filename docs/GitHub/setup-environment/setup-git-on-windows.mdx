GitHub provides two ways of installation: GitHub Desktop, and the command line by installing the Git software on your system. Personally, from a developer perspective, I would suggest you use the command line, as it comes in handy and gives more flexibility in solving bugs and doing more with version control, especially when conflicts happen with Git. This tutorial is focused on the command line version.

</LessonHeader>

### Step 2: Select the version you want to install {#step-2-select-your-version-you-want-to-install}

You can find out which system you are using by right-clicking the `This PC` icon, choosing `Properties` and checking the System type.

### Step 3: Understanding the Interface {#step-3-understanding-the-interface}

Next, Git will ask you to install a couple of components. You can check Additional icons to add them on the Desktop, leave the rest as default and click Next.

1. On the next screen, click Next, and make sure the Start Menu folder name is Git.
2. Next, choose the default editor. You can use your own editor (I am using Visual Studio Code) or keep Vim as the default editor.
