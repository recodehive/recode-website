## Ranks and the leaderboard

The leaderboard orders contributors by points. The top three earn the leaderboard recognition badges. When two contributors have the same points, the one with more merged PRs ranks higher. The leaderboard updates every {REFRESH_HOURS} hours, and the rank badges use the all-time ranking.

<Podium />

## Achievement badges

13 badges, from your first merged pull request to the top of the leaderboard. The hexagon comes from a honeycomb: it connects every badge to the hive and stands for collaboration, structure and growing together. Merged PR counts include only pull requests that scored points. Tap a badge to see what it means.
